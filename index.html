🌐 Hosting & Installation Instructions
  1. Local run (any device): open index.html directly in Chrome/Edge/Safari.
  2. Install as app (PWA): on mobile use "Add to Home Screen"; on desktop click ⬇ Install in header. Use HTTPS for full install support.
  3. Simple hosting options:
    • GitHub Pages: push index.html to a repo and enable Pages in repo settings → URL is ready to share.
    • Netlify Drop: visit app.netlify.com/drop and drop the file — instant HTTPS URL.
    • Local server: in this folder run python -m http.server 8000 then open http://localhost:8000.
  4. Cross-device sync: open the hosted URL on every device, enter the same Store ID, and log in. Use the ↗ Share button to send the URL to your team.
  5. Cloud sync (optional, future): out-of-the-box uses device LocalStorage. For true multi-device sync, host and optionally add Firebase (stubs included in app source).
